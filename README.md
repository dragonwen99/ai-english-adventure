# 英语冒险岛 / AI English Adventure

面向中小学生的 AI 游戏化英语学习产品 MVP。

## 核心理念

学习行为本身就是游戏行为：
- 拼写正确 = 攻击
- 连续正确 = Combo / 暴击
- 错词 = 怪物
- 复习 = 追捕怪物
- 单元测试 = Boss 战
- 掌握知识 = 战斗力成长

## 当前 MVP

已实现第一条可交互学习闭环：学生首页 → 世界地图 → 关卡 → 拼词 → Combo → Boss HP → XP / 星星 → 解锁下一关。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。

## 商业原则

免费层提供完整基础学习闭环；Pro 主要为 AI 个性化、自定义教材、深度学习报告和家庭能力付费。游戏机制用于提高学习动力与留存，不采用付费获得学习优势的设计。
